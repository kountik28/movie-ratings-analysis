# movie-ratings-analysis
Analyzing and Visualizing Movie Ratings using Python
This project focuses on analyzing and visualizing movie ratings.

Tasks:
- Data Cleaning
- Summary Statistics
- Data Visualization
- Identify top-rated movies and genres# 🎬 Movie Ratings Analysis Project

## 📌 Overview

This project focuses on analyzing and visualizing movie ratings data to extract meaningful insights about different genres and their performance. It demonstrates fundamental data analysis skills including data cleaning, exploration, and visualization.

---

## 🎯 Objectives

* Load and explore movie dataset
* Perform data cleaning and preprocessing
* Analyze ratings and genres
* Visualize data using graphs
* Identify top-rated movies and trends

---

## 📊 Dataset Information

The dataset contains the following columns:

* **Movie** → Name of the movie
* **Genre** → Category of the movie (Action, Sci-Fi, Romance, etc.)
* **Rating** → IMDb-style rating (out of 10)
* **Year** → Release year

---

## 🛠️ Tools and Technologies Used

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## 🔍 Steps Performed

### 1. Data Loading

* Loaded dataset using Pandas
* Displayed initial rows using `head()`

### 2. Data Exploration

* Checked dataset shape, info, and summary statistics
* Understood structure and data types

### 3. Data Cleaning

* Checked for missing values
* Removed null values (if any)

### 4. Data Analysis

* Calculated average movie rating
* Identified top-rated movies
* Analyzed number of movies per genre
* Computed average rating by genre

### 5. Data Visualization

* Countplot for genre distribution
* Histogram for ratings distribution
* Bar chart for average ratings by genre

---

## 📈 Key Insights

* Action and Sci-Fi movies tend to have higher ratings
* "The Dark Knight" is the highest-rated movie in the dataset
* Ratings are generally distributed between 7.5 and 9.0
* Some genres have more representation than others
